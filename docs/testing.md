# 测试策略

本仓库如何分层测试，以及让绿色套件有意义的规则。命令在根 [AGENTS.md](../AGENTS.md)；方法细则在 [dsdev-testing-policy](../.claude/skills/dsdev-testing-policy/SKILL.md)。

## 分层

- **Unit**（`pnpm test`）：按模块的行为测试，与它锻炼的模块同住；每个 registry 有释放安全测试。
- **Coverage gate**：按文件 100% 行覆盖是 CI 的门；未覆盖行多半是该删的死代码。行覆盖必要而不充分。
- **真实入口 e2e**：通过构建后的 bin/CLI/进程启动，断言外部可观察结果。
- **期望输出 / 快照**：用户或模型可见的非平凡变更在同 PR 更新期望输出。

## 四原则

1. **测真实入口路径**：产品可见模块需要非 unit 的真实组合测试；手装对象不算。
2. **验证世界，不验证自述**：重读文件/重跑命令；断言未触碰的文件字节相同。
3. **只 mock 昂贵或非确定的边界**（网络、时钟、外部模型）；下游全部真实。
4. **守卫必须能变红**：引入回归、看红、还原。

## 执行拓扑

测试在多个 worker 进程并发运行；进程隔离不隔离端口、可预测路径、外部服务。每个获取的资源通过拆卸归还；只在单独运行时通过的测试是测试缺陷。
