# AGENTS.md — Agent Notes

Agent Note 是 Agent 写的 RFC：保留理由、备选、后果与必需验证的持久记录。遵循 [文档标准](../../docs/AGENTS.md) 与 [Agent Note 规则](README.md)。

**每个新 note 触发取代检查。** 在活跃树里搜索覆盖同一决策或机制的旧 note，分类完全/部分取代，同 PR 归档每个符合条件的 implemented note。部分取代的保持活跃并互链。

[`archived/`](archived/AGENTS.md) 下的文件是冻结的历史快照：永不编辑，不作为当前依据。
